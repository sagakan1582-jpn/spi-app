## 問題を足す手順
1. `data/` に新しいファイルを作る（例：`soneki_3.js`）。`BANK['損益']={3:{concept:[…],practice:[…],applied:[…],real:[…]}};` と `LESSON['損益']={3:[…]};` を書く。分野名は config.js の CURRICULUM と同じ文字にする。
2. index.html の `js/app.js` の行より前に `<script src="data/soneki_3.js"></script>` を足す。
3. 公開しなおす。

## 問題1問の形
```
{q:'問題文', c:['選択肢A','B','C','D','E'], a:正解の番号(0始まり), inw:'内訳の説明（省略可）',
 fig:図, calc:'計算（<br>で改行）',
 inwh:'内訳の見出し（省略可。順列・組合せは「整理」）', sec:目標秒数（省略可。省略時は指標ごとの値。図2本の問題は90）, id:'固定ID（省略可。省略時は問題文から作る）'}
```
図は2種類。
- 矢印の線分図：`{whole:{n,r,v,ask}, parts:[{n:ラベル, r:割合, v:量, w:幅, ask:1}]}` または段を自由に組む `{rows:[[…],[…]]}`
- 表（カルノー表・精算表）：`{table:{head:[…], rows:[[…],…]}}`。セルを `'!9'` にすると求めるマス（オレンジ）、`'?'` は空欄の?

## 「すべて選ぶ」形式（推論）
- `a` を配列（例 `a:[0,3]`）にすると複数選択になる。選択肢 `c` は最大8個（A〜H）。選んで「決定」を押す。全部一致で正解。
- 問題文の最後に「当てはまるものをすべて選びなさい。」と書く。

## 数値を変える問題（テンプレート）
問題の絶対数を増やすため、既存の問題を「文はそのまま、数値だけ毎回変える」テンプレートにする（ユーザー指示 2026-11-15）。
- 実践（単純な数値・実際の数値）：問題集（実際の過去問）の問題文に準拠し、数値だけを変える。文章を独自に作らない。
- 概念・練習：今の作り（単純化した問題）のまま、数値を変えて数を増やす。
- 置き場所：`data/gen_分野.js`（全指標分）。index.html では元の data ファイルより後に読み込む。元の問題は消さない。
```
(function(){var B=BANK['損益'][3];
B.practice.push({id:'son3p-1',make:function(R){
  var c=R.pick([400,500,600,800]), r=R.pick([10,20,25,30]), p=c*r/100, t=c+p;
  return {q:'仕入れ値が'+c+'円の商品に、仕入れ値の'+r+'%の利益を見込んで定価をつけた。この商品の定価は何円か。',
    c:…5つ（正解 t と、よくある間違い c*(1-r/100)・c+r・p など。重複しないように）, a:正解の番号,
    inw:SE3I, fig:SE3('?','','0円',c+'円',p+'円','t'), calc:'見込み利益 '+c+' × '+r/100+' ＝ '+p+'<br>定価 '+c+' ＋ '+p+' ＝ '+t};
}});})();
```
- make は毎回、問題・選択肢・正解・解説・図を数値から計算して返す。答えはコードで計算するので、数値の範囲は「割り切れる」「答えが整数・きれいな値」になるものだけを選ぶ（R.pick で候補から選ぶのが安全）。
- 選択肢は5つ（すべて選ぶ形式は元と同じ数）、正解の位置はシャッフル、重複なし。誤答は計算ミスで出やすい値にする。
- **解けない問題・間違いを防ぐ（ユーザー指示）**：make は選んだ数値を `v:{…}` として返す。テンプレートには必ず `verify:function(v){ return 答えの文字列（選択肢と同じ表記。すべて選ぶは配列） }` を付け、make とは**別の方法**（総当たり・数え上げ・逆算・分数での計算など）で答えを出す。検査ツールが毎回 verify の答えと正解の選択肢を照合し、誤答に正解と同じ値が混じっていないかも見る。さらに、元の問題の数値を入れたときに元の答えになることを確かめる。
- 検査：`node /mnt/project-files/app-tools/check.js 分野名` で200回ずつ作って、選択肢の数・重複・正解番号・NaN を確かめる。0件になるまで直す。

## 解き方（LESSON）の書き方
具体的な例題を先に出し、問題文のどの数字が図のどこに入り、どう変わるかを1つずつ追う（ユーザー指示 2026-11-15）。抽象的な説明から始めない。
```
LESSON[分野][指標]=[
 {h:'例題1', q:'実際のSPIの文体の問題文。数字は <mark>480人</mark> のように囲む'},
 {h:'ステップ1 内訳を探す', p:'問題文の「<mark>…</mark>」から…と分かる', fig:内訳だけの図},
 {h:'ステップ2 図・表を描く', p:'<mark>480人</mark>は全体なので一番上の矢印の下に書く…（数字ごとに1文）', fig:問題文の数字を入れた図（求める所は ask）},
 {h:'ステップ3 空白を埋める', p:'どの空白を、どの数字から、どの計算で埋めるか', fig:埋めた図, p2:'計算'},
 {h:'答え', p:'…'},
 （例題2・3で、その指標でよく出る形を同じ手順で追う）
 {h:'まとめ', p:'短く'}
]
```
- 各ステップの図は前のステップの図に1つずつ数字を足していく形にする（どこが増えたか分かるよう、新しく入れた数字は <mark> で囲んでよい）。
- 例題は3つまで。指標ごとの難しさ（指標4の仕掛け、指標5の x・1,000 の置き方、推論の場合分け）は例題の中で数字を追って見せる。

## 守るルール
- 問題文は実際のSPIの文体（「ある〜のうち、〇%が…である。〜は何人か。」）。省略しない。選択肢はA〜Eの5択。
- 解き方は講座の3ステップ（内訳を探す→図・表を描く→空白を埋める）。解説は 内訳→図→計算→答え。
- UIに説明文を足さない。色は推奨（青）・正解（緑）・不正解（赤）・?（オレンジ）だけ。タイトル画面だけ青。
- テストセンター受検が前提。WEBテスティングやペーパーテストでしか出ない分野（ア、イの情報・物の流れ・グラフの領域・条件と領域・推論【命題】）は作らない。
- 当面は非言語だけ。推論・植木算は資料がないので、全体設計書（https://claude.ai/artifact/2SehuZkJ9XNUQq4Ah27ybM）の「講座にない分野の解き方（自作）」に従って作る。指標3の順列・組合せ・確率は「公式の使い方」として作る。

## 複数スレッドで作るとき
- 問題を作るスレッドは、自分の `data/分野_指標.js` だけを書く。index.html・js/・style.css は触らない。
- 答えと計算はスクリプトで確かめる。できたら「アプリ全体設計」スレッドに知らせる。index.html への追加と公開はそのスレッドがまとめて行う（公開がぶつからないように）。

## 時間と記録（AIモードの土台）
- 目標時間は config.js の TARGET_SEC（指標3=90秒、4・5=60秒、6・7=90秒）。問題の `sec` が優先。
- 分野別勉強モードでは、config.js の TIMER（今は「実践（実際の数値）」×指標4から）だけ本番と同じタイマー（青→黄→赤、0で時間切れ＝不正解）。ほかの段階は時間を測って結果に秒数だけ出す。
- 解答はすべて localStorage の `mainichi-spi-log-v1` に記録：{t日時, f分野, l指標, s段階, q問題ID, r結果, sec秒, tg目標秒, pick選んだ番号}。r は fast（正解・時間内）／slow（正解・遅い）／wrong（不正解）／timeout（時間切れ）。

## AIモード（js/ai.js）
- 設計は全体設計書の「AIにお任せ教育モード」の章どおり。習得 m：0未学習→1理解（概念クリア）→2正確（実践②クリア）→3速い（実践②を本番タイマーで3連続正解）→4定着（復習で時間内正解）。復習間隔は1日→5日→14日。
- 初回は今の指標の各分野の実践②を1問ずつ（本番タイマー）。時間内正解の分野は「正確」から始める。
- 実践（単純な数値・実際の数値）で不正解 → 3ステップ診断。小問は既存の問題から自動で作る（内訳＝他分野の inw、図＝同じ分野の別の図、計算＝同じ分野の別の calc を誤答にする）。最初に間違えたステップに応じて段階を戻し、2問練習させる。
- 全分野が「速い」以上で指標チェック（実践②10問、本番タイマー、8問以上で次の指標へ）。次の指標に中身がなければ、復習と実践を出し続ける。
- タイマー：m0 なし、m1 目安バー（時間切れなし）、m2以上 本番と同じ。

## 模擬テスト（js/mock.js）
- 20問・全体23分。1問ごとに本番タイマー、戻れない、解説は終了後。問題は各分野の applied と real を共用（同じテスト内で重複なし）。
- 指標4から開始。2問続けて正解で1つ上、2問続けて間違えで1つ下（中身のある指標の範囲で）。
- 推定段階＝最後の10問の指標の平均を四捨五入。いちばん上の指標を5問以上解き8割正解なら+1、全体の正解が4割未満なら−1（2〜7）。推論（指標6・7）があるときは、前半10問が計算（指標5まで）、後半10問が推論（指標6から開始）。計算の推定が5以上で、指標6の推論が6割以上なら6、さらに指標7を3問以上解き6割以上なら7。
